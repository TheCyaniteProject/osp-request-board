# Kieee's Open Software Project

## Request Board

This is a long-term project where people can request free and open-source alternatives to existing software and original software. Requests are submitted through this repository’s Issues page, and the projects I decide to take on will will be released to the public domain.

I can’t promise that I’ll make every request. I’ll favor ideas that catch my interest, seem useful, and are realistically within my ability to build. Still, if you have an idea, I’d like to hear it.

## Why I’m Doing This

The simple answer is that I really like open software.

I like being able to look at the code, tear it apart, figure out how it works, and put it back together. Open-source projects are a great way for developers to learn because you can see how real software is built instead of being limited to tutorials and tiny examples.

Open-source software also gives people options. Not everyone can afford expensive programs, and subscription-based software can turn a useful tool into a permanent bill. I want to help create alternatives that people can use, learn from, modify, and keep.

This project gives me an excuse to build interesting things while hopefully making software a little more open and accessible along the way.

## What Kinds of Requests Can I Accept?

If you are requesting an alternative to existing software:

- There should not already be a complete and actively maintained free or open-source alternative. If the available alternatives are incomplete, abandoned, or missing important features, the request may still be a good fit.
- There needs to be enough public information for me to understand and research the original software. Screenshots, documentation, reviews, YouTube videos, and demonstrations are all useful.
- The goal must be to create a new open-source program inspired by the original software’s useful features-not to copy proprietary code, branding, artwork, or other protected material.

I also can’t take on anything that requires me to pay ongoing expenses or personally operate a dedicated server. Services with costs that can reasonably be left to each user-such as using their own API key or self-hosting an optional server-are fine.

Original software ideas are welcome too. You do not need to have every detail worked out, but I need enough information to understand what the program is supposed to do and who it would be useful for.

My main targets are Windows and Linux, with Linux releases provided as `.AppImage`s. I may accept simple Android app requests, but Android development is not my specialty. Projects will be made with Node.js (CLI, web, or Electron) or C#, depending on what fits the project best. I will not be taking on game projects because they tend to require too many expensive assets.
